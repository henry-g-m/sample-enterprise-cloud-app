==Re-loading the application locally===
With docker compose, you can re-load the application without restarting the container. This is useful for development when you make changes to the code.
   docker compose restart app
With uvicorn
    uvicorn src.app:app --reload --host 0.0.0.0 --port 8000

= GitHub authentications against Azure =
App registration
gh-actions-entdemo is an identity in Azure AD that GitHub Actions can log in as. Think of it as a "robot user" that Terraform/az acr build run as when CI executes — that's what lets a workflow run create/modify real Azure resources.

OIDC federated credentials (what I set up instead)
No password exists at all. Instead, Azure AD is told: "trust tokens issued by GitHub's OIDC provider, but only tokens whose subject claim matches one of these exact strings":
- repo:henry-g-m/sample-enterprise-cloud-app:ref:refs/heads/master
- repo:henry-g-m/sample-enterprise-cloud-app:environment:production
- repo:henry-g-m/sample-enterprise-cloud-app:pull_request

When a GitHub Actions job runs, GitHub mints a short-lived signed token describing exactly what's running (this repo, this branch/environment/event). The azure/login step hands that token to Azure, Azure checks the signature and the subject string against the three entries above, and if it matches, issues a short-lived Azure access token for that job only.
